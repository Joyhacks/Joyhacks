# OFFFREQ — An independent listening room

A fictional, editorial music discovery experience designed as a frontend portfolio case study. Built with **Next.js**, **React**, original typographic record-sleeve artwork, responsive layouts, and a locally generated playable demo player.

**Positioning:** Good music. No shortcuts.  
**Tagline:** Tune out. Find more.  
**Status:** Design/engineering concept, not a production music streaming service.

## What's inside

- **Discover** (`/`) — original, art-directed home experience with a featured issue, new finds and hand-curated mixes.
- **Search** (`/search`) — live title, artist, genre, album and mood filtering.
- **The mixes** (`/mixes`) — collections with their own pages and playable queues.
- **Your shelf** (`/library`) — locally persisted saved tracks; no account required.
- **The story** (`/about`) — brand manifesto and honest portfolio disclaimer.
- **Persistent player** — playback, play/pause, skip, shuffle, repeat, volume, scrubbing and a queue drawer, across routes.
- **16 original SVG sleeves** — generated by `scripts/generate_artwork.py`, editable without relying on stock imagery.
- **Responsive UI** — laptop, tablet, mobile navigation and reduced-motion accommodation.

## Run locally

Requires Node.js 20.9+ and an internet connection once for installing dependencies. Audio works offline after the page loads.

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production compile, use `npm run build` and `npm run start`.

## Deploy to Vercel

Import this project into Vercel, use the **Next.js** framework preset and the default build command `npm run build`. No environment variables or Spotify credentials are needed. Dependencies target the Next.js 15.5 maintenance line with September 2026 security patches. The project is a frontend concept rather than a licensed streaming platform.

## Tests and verification

## Audio and content notes

- The featured artists, track titles and albums are **fictional portfolio data**; they do not correspond to commercially released music.
- Playable 24-second audio clips are synthesized locally using `lib/demoAudio.js` when the listener presses Play. There are no outside audio URLs, accounts, or API keys. The clips are musical placeholders, not recordings by the fictional artists.
- For a real streaming product, obtain rights to actual music, build authentication/catalogue services, and replace synthesized previews with properly licensed recordings.
- Saved tracks are browser-local and are not synchronized across devices.
- `DESIGN_PREVIEW.html` is a **static art-direction preview**, not the running interactive app. Use `npm run dev` to test real navigation and playback.
- This is a **frontend demonstration**, not a real music catalogue, upload system, payment service, or backend.
